# Hero Video Directory

Place your hero video file here:
- **File name:** `hero.mp4`
- **Path:** `/public/media/hero/hero.mp4`
- **Format:** MP4 (H.264 codec recommended)
- **Resolution:** 1920x1080 or similar aspect ratio
- **Size:** Keep under 10MB for optimal loading
- **Settings:** No audio track, loop-friendly

Optional poster image (fallback):
- **File name:** `hero-poster.jpg`
- **Path:** `/public/media/hero/hero-poster.jpg`
- **Format:** JPG
- **Resolution:** 1920x1080
- **Size:** ~300KB

The page will work without these files - it will show a solid background color as fallback.
