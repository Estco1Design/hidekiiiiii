# HIDEKI MEDIA UPLOAD GUIDE

## 📁 Структура папок создана в: `/public/media/`

---

## 1. ГЛАВНАЯ СТРАНИЦА (HOME)
**Папка:** `public/media/home/`

### Файлы для загрузки:
- `hero-video.mp4` — главное видео (горизонтальное, 720p, до 10 МБ, без звука)
- `hero-poster.jpg` — стоп-кадр из видео для быстрой загрузки (1920x1080, ~300 КБ)
- `portrait-main.jpg` — основной портретный снимок (вертикальный, высокий)
- `floating-detail.jpg` — небольшая детальная фотография (для парящего эффекта)
- `editorial-spread.jpg` — редакционное фото (широкое, асимметричное)
- `object-001-teaser.jpg` — тизер для магазина (драматичное фото объекта 001)

## 4. ПРОЕКТЫ (WORK)
**Папка:** `public/media/work/`

### Для каждого проекта создай подпапку с названием проекта (латиница):
Пример: `public/media/work/balmain-campaign/`

#### Внутри каждой папки проекта:
- `cover.jpg` — обложка проекта (главное изображение)
- `preview.mp4` — короткое превью видео (до 5 сек, без звука, до 3 МБ)
- `shot-01.jpg`, `shot-02.jpg`, `shot-03.jpg`... — фотографии проекта
- `film.mp4` — если есть полноценное видео внутри проекта
- `film-poster.jpg` — постер для видео

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Изображения:
- Формат: JPG, PNG, WebP
- Максимальная ширина: 2500px
- Вес: до 500 КБ каждое (сжимай через TinyPNG или Squoosh)
- Имя файла: только латиница, цифры, дефисы (без пробелов!)

### Видео:
- Формат: MP4 (кодек H.264)
- Разрешение: 1280x720 (720p) для фона, 1920x1080 для проектов
- Звук: НЕТ (обязательно удаляй аудиодорожку)
- Длительность: 6–15 секунд для главной, до 60 сек для проектов
- Вес: до 10 МБ для главной, до 20 МБ для внутренних страниц
- Атрибуты: autoPlay, loop, muted, playsInline

---

## ЧТО ДЕЛАТЬ ПРЯМО СЕЙЧАС:

1. Положи видео и постер в `public/media/home/`
2. Переименуй их точно как указано выше
3. Напиши "ГОТОВО" — я обновлю код главной страницы
